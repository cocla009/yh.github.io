1. State Value（状态价值函数）

1. 定义

状态价值函数（State-Value Function）表示：在遵循策略 的情况下，从状态 出发，未来能够获得的累计折扣回报的期望。

2. 状态价值函数的三个特点

（1）它是状态的函数

不同状态可能具有不同的价值，因为从不同状态出发，未来能够获得的累计回报可能不同。

（2）它与策略有关

相同状态下，采用不同策略，可能获得不同的期望回报，因此状态价值也可能不同。

（3）它表示状态的价值

状态价值越大，意味着按照当前策略从该状态出发，能够获得的期望累计回报越高。在相同状态下比较不同策略时，状态价值较高的策略通常更好。

如果策略、奖励和状态转移都是确定性的，那么从某个状态出发，后续的动作、奖励和状态转移都不会产生随机变化。

6. 贝尔曼方程中的重要概念

（1）Bootstrapping（自举）

计算当前状态价值时，需要使用下一状态的价值。

即利用其他状态的价值来计算当前状态的价值，这种方式称为自举。

（2）Policy Evaluation（策略评估）

当策略 和环境模型已知时，通过求解贝尔曼方程，计算各个状态对应的价值。

这个过程称为策略评估。

（3）Dynamic Model（环境动态模型）

环境模型主要由以下两个概率分布描述：

它们描述了智能体执行动作后，环境可能返回什么奖励，以及可能转移到什么状态。

Iterative Policy Evaluation（迭代策略评估）

迭代策略评估是一种基于贝尔曼方程的动态规划方法。

它不直接求解贝尔曼方程，而是从一个初始状态价值开始，通过不断迭代更新状态价值，使其逐渐收敛到给定策略对应的真实状态价值。

4.Action Value（动作价值函数）

1. 从 State Value 到 Action Value

（1）State Value（状态价值）

表示智能体从某个状态出发，按照策略 继续行动，未来能够获得的期望累计回报。

（2）Action Value（动作价值）

表示智能体从某个状态出发，先执行指定动作 ，之后继续按照策略 行动，未来能够获得的期望累计回报。

其中：

  • ：当前状态。
  • ：当前指定执行的动作。
  • ：从当前时刻开始的累计折扣回报。
  • ：当前采用的策略。

注意：Action Value 固定当前时刻执行的动作，后续动作仍然按照策略 选择。

（3）为什么需要 Action Value？

State Value 只能评价一个状态的整体价值，而 Action Value 可以进一步评价在该状态下，不同动作分别有多大的价值。

通过比较不同动作的价值，可以判断哪个动作更值得选择。
