3.1 Motivating Example: How to Improve Policies?

1. 为什么需要寻找最优策略？

强化学习的最终目标是寻找最优策略（Optimal Policy）。

已有策略不一定是最好的，因此需要一种数学方法评价当前策略，并寻找更好的动作。

本节通过 State Value 和 Action Value 说明如何改进策略。
