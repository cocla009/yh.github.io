强化学习笔记（一）：基础概念

2026年11月21日 880 字 大概 3 分钟

1.State(状态)

就是我们机器人在环境中的一个状态（这个状态是要自己定义的）

所有的状态放在一起就是状态空间： (这里就是说共有N个状态组成的状态空间)

2.Action(动作)

就是我们机器人可以执行的动作(也是要自己定义的)

动作空间： (这里指的是，想要达到这个状态，所要执行的动作顺序的集合)

这里要指出，动作空间是依赖于状态的，不同状态他的动作空间是不一样的

3.State transition(状态转移)

就是当我们采取一个动作，我们的状态会从

State transition probability: 这个主要可以用来描述随机概率，这里的意思就是，我们当前在S1，通过a2这个动作到S2的概率有0.5

4.Policy(策略)

策略就是指，要从某个状态到达另一个状态，所要完成的动作

这里就是指的，表示在状态 s_1 下，策略选择动作a_2 的概率为 100%。，也就是确定的策略

该状态下所有可选动作的选择概率之和为 1

5.Reward(奖惩)

agent在某一状态下，采取某一动作，会得到奖惩，正向就是鼓励，反向就是惩罚

是一种我们与机器交互的手段

6.Trajectory(轨迹) and return

trajectory就是state-action-reward chain

return 就是沿着这个trajectory所能得到的所有rewards，可以用来衡量一个trajecotry的好坏

7.Discounted return

像上面的trajectory实际上到target后仍会沿着policy继续进行，这样的话return最终会得到一个无穷，也就是会发散掉

为了避免这个情况，我们引入了discount rate

discount rate 与return结合就得到了 discount return

我们可以通过调整discount rate 来调整训练过程中，我们的模型是更加注重眼下，还是更加注重未来

8.Episodic Tasks（回合式任务) and Continuing Tasks（持续性任务）

智能体按照某个策略与环境交互，当它到达某些终止状态（Terminal States）时，交互就会停止。这一段完整的状态转移过程就叫作一个 Episode（回合）。

也就是说，一个 Episode 通常被认为是有限长度的轨迹。

这种具有回合终止机制的任务叫作：

Episodic Tasks（回合式任务）

例如：

  • 下棋：一局棋结束，当前回合结束。
  • 游戏：角色死亡或通关，一局游戏结束。
  • 机器人导航：到达指定目标，当前导航任务结束。

有些任务可能根本不存在终止状态，智能体与环境之间的交互不会自然结束。

这种任务叫作：

Continuing Tasks（持续性任务）

例如：

  • 一个持续运行的机器人控制系统。
  • 持续运行的服务器资源调度。
  • 不断进行的交通信号灯控制。

这些任务没有明确的完成时刻，智能体需要一直运行。

那么智能体到达目标状态后，任务究竟应该结束，还是允许它继续与环境交互？

Option 1：将目标状态视为吸收状态（Absorbing State）

把目标状态设置为一个特殊的状态，一旦进入，就永远不会离开。

Option 2：将目标状态视为普通状态（Normal State）

不再把目标状态当作特殊状态，而是把它当作一个普通状态，并且为它定义正常的策略。
